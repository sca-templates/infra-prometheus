# Prometheus — Service Guide

Prometheus observability for the local `aws/` monorepo. Follow the sibling
patterns exactly (`kafka/`, `consul/`, `vault/`) — this repo is a copy-paste
evolution of them.

## Project

Central Prometheus TSDB (30-day retention) scraping Vault, Consul, Postgres,
Redis, Kafka Connect (Debezium CDC) and future NestJS microservices, with
bundled postgres-exporter, redis-exporter and a JMX exporter for Kafka Connect.
UI: <http://127.0.0.1:9090> (loopback only). Production reference (same image
versions): `../ansible/roles/observability/`. Full spec: `../prometheus.md`.

## Layout

- `compose.yml` — prometheus, postgres-exporter, redis-exporter,
  kafka-connect-exporter; the broker kafka-exporter job stays commented.
- `prometheus.yml` — scrape configs (global 15s, `external_labels: project=sca,
  environment=dev`).
- `kafka-connect-jmx.yml` — JMX exporter rules for Kafka Connect (`debezium.*`,
  `kafka.connect:*`).
- `Makefile` — targets: `help setup vault-secrets env up all down stop restart
  logs ps validate clean` (idempotent).
- `scripts/` — `vault-secrets.sh`, `gen-env.sh`, `validate.sh`.
- `.env.example` — non-secret vars and ports; `.env` is generated, gitignored.
- `.github/` — CI (`validate.yml`), PR template, CONTRIBUTING, dependabot.
- `.mcp.json` + `.claude/` — Claude Code + codegraph MCP wiring.
- `docs/handbook/` — runbooks / AI handbooks for this service.
- `0.Project_info/` — user tooling (commit/merge/prompt flows); do not touch.

## Commands

- `make help` — all targets.
- `make setup` — `vault-secrets` + `env`.
- `make up` / `make all` — compose up + `../scripts/wait-healthy.sh prometheus`.
- `make validate` — shellcheck + `docker compose config` + `promtool check
  config` + `/-/healthy` + `up{}` sanity query.
- `make down stop restart logs ps clean` — stack lifecycle.
- CI mirrors the same checks in `.github/workflows/validate.yml`.

## Conventions

- The compose file is `compose.yml`, not `docker-compose.yml`.
- Shell scripts: `set -euo pipefail` + a header comment only; no other comments.
- `.env` is gitignored and generated by `scripts/gen-env.sh` from Vault
  `secret/api-template/dev` (`DATA_SOURCE_NAME`, `REDIS_PASSWORD`), `chmod 600`.
  Never commit `.env` or secrets.
- Vault token mounted read-only: `../vault/data/secrets/root-token.txt` →
  `/etc/prometheus/vault-token`. After Vault re-init (`make clean`) the token
  changes: re-run `make up` to remount it.
- Network: `kafka-network` is external (name resolution). `redis` and `vault`
  are NOT on it → reached via `host.docker.internal` (`extra_hosts:
  host-gateway`).
- Consul registers services with TCP checks on `127.0.0.1:<port>` in
  `../consul/scripts/register-services.sh` and validates them in
  `../consul/scripts/validate.sh`.
- Microservice jobs (9101–9104) and the broker kafka-exporter job stay
  **commented** until a real target exists (`apache/kafka:3.7.1` ignores
  `KAFKA_JMX_PORT`; do not add fragile `KAFKA_OPTS`). Never touch the running
  kafka stack.
- Content in English; changes land through a PR.

## CodeGraph

`codegraph_explore` MCP tool) over grep/read for code questions. The index is
currently tiny (pre-implementation); run `codegraph sync` after the core
implementation to refresh it.
